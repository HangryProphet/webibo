Wiza: "Hello, aspiring web developer! 👋 I'm Wiza, and I'll be your guide through the magical world of HTML. Welcome to Webibo - where we turn curious minds into confident coders!

Quick Facts:
* HTML is NOT a programming language
* It's a markup language for structuring content

Page 2/4: The HTML Document Structure
Wiza: "Every HTML document follows a specific structure. Here's the basic blueprint:
html
<!DOCTYPE html>
<html>
  <head>
    <!-- Behind-the-scenes info -->
  </head>
  <body>
    <!-- Visible content -->
  </body>
</html>
Let's break this down:
1. <!DOCTYPE html> - This tells the browser, 'Hey, I'm using modern HTML!'
2. <html> - The root element that wraps EVERYTHING else
3. <head> - Contains invisible information (metadata, title, links)
4. <body> - Contains ALL visible content
Think of it like a house:
* <!DOCTYPE html> = Building permit
* <html> = The entire property
* <head> = Blueprints (invisible to visitors)
* <body> = The actual house (what people see)"
Page 3/4: The Head vs Body Sections
Wiza: "Let's explore the difference between <head> and <body> with an example:
html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
    <!-- This text WON'T appear on the page! -->
  </head>
  <body>
    <p>Welcome to my website!</p>
    <!-- This text WILL appear on the page! -->
  </body>
</html>
Key Difference:
* <head> content: Never visible on the page itself
   * Page title (shown in browser tab)
   * Character encoding
   * Links to CSS files
   * Meta descriptions
* <body> content: ALWAYS visible to visitors
   * Text paragraphs
   * Images
   * Buttons
   * Videos
   * Headings
Pro Tip: Right-click any webpage and select 'View Page Source' to see real HTML in action!"

LEVEL 2: THE VERY BEGINNING (Multiple Choice - 10 Questions with Explanations)
Wiza: "Great job with the lecture! Now, let's check your understanding with 10 multiple-choice questions. Choose the ONE correct answer for each, and I'll explain why it's correct!"
1. What does HTML stand for?
a) Hyper Transfer Markup Language
b) High Tech Modern Language
c) Hyper Tool Markup Language
d) Hyper Text Markup Language
Correct Answer: d
Explanation: HTML stands for Hyper Text Markup Language. It's called "Hyper Text" because it can contain links to other documents, and "Markup Language" because it uses tags to structure content.
2. Which tag contains ALL other HTML elements?
a) <body>
b) <container>
c) <html>
d) <main>
Correct Answer: c
Explanation: The <html> tag is the root element that wraps EVERYTHING else in an HTML document. All other tags must be inside it.
3. Where does visible webpage content go?
a) In the <head> section
b) Between <!DOCTYPE> and <html>
c) In the <body> section
d) In the <content> section
Correct Answer: c
Explanation: The <body> section contains ALL visible content that users see in their browser window. The <head> contains invisible metadata.
4. What is the purpose of <!DOCTYPE html>?
a) To create the main heading
b) To contain the page content
c) To declare the document type
d) To add a title to the page
Correct Answer: c
Explanation: <!DOCTYPE html> tells the browser that this is an HTML5 document and helps it render the page correctly. It's a declaration, not a tag!
5. Which section contains the page title?
a) <body>
b) <footer>
c) <header>
d) <head>
Correct Answer: d
Explanation: The <title> tag, which sets what appears in the browser tab, goes inside the <head> section along with other metadata.
6. True or False: Content inside <head> appears on the webpage.
a) True
b) False
Correct Answer: b
Explanation: False! Content inside the <head> section is never visible on the webpage itself. It's for behind-the-scenes information like page titles, character encoding, and CSS links.
7. What appears in the browser tab?
a) Content from <h1> tags
b) Content from <p> tags
c) Content from <title> tags
d) Content from <body> tags
Correct Answer: c
Explanation: The text inside the <title> tag appears in the browser tab, bookmarks, and search engine results. It's like the name tag for your webpage!
8. Which comes first in an HTML document?
a) <head>
b) <body>
c) <!DOCTYPE html>
d) <html>
Correct Answer: c
Explanation: <!DOCTYPE html> always comes first in an HTML document. The order is: <!DOCTYPE>, then <html>, then <head>, then <body>.
9. HTML is primarily used for:
a) Making websites interactive
b) Styling webpages
c) Structuring webpage content
d) Creating animations
Correct Answer: c
Explanation: HTML's main job is to provide structure and content to webpages. For styling, we use CSS, and for interactivity, we use JavaScript.
10. Which tag pair is ALWAYS required in HTML?
a) <head> and </head>
b) <title> and </title>
c) <html> and </html>
d) <body> and </body>
Correct Answer: c
Explanation: While <head> and <body> are important, technically only <html> is absolutely required. However, good HTML should include all three!

Page 1/3: Organizing Your Content
Wiza: "Welcome back! Now that you have your HTML skeleton, let's add some muscles and skin! 🏋️
Today, we'll learn about headings and paragraphs - the most common ways to add text to your webpage.
Headings (<h1> to <h6>):
HTML provides SIX levels of headings, from most important to least:
html
<h1>Main Title (Biggest)</h1>
<h2>Section Title</h2>
<h3>Sub-section</h3>
<h4>Small heading</h4>
<h5>Smaller heading</h5>
<h6>Smallest heading</h6>

Page 2/3: Paragraphs and Text
Wiza: "For regular text, use the <p> (paragraph) tag:
html
<p>This is a paragraph of text.</p>
<p>This is another paragraph.</p>
Why use <p> tags?
      * They create natural spacing between text blocks
      * They make your content accessible
      * They help search engines understand your page
      * They're easy to style later
Example Page:
html
<!DOCTYPE html>
<html>
<head>
    <title>My Blog</title>
</head>
<body>
    <h1>Welcome to My Travel Blog</h1>
    <h2>Latest Adventure: Japan</h2>
    <p>Last month I visited Tokyo and it was amazing!</p>
    <p>The food, culture, and people were incredible.</p>
    <h3>My Favorite Spots</h3>
    <p>Shibuya Crossing was unforgettable...</p>
</body>
</html>
Page 3/3: Best Practices
Wiza: "Headings Hierarchy Tip:
Always maintain a logical order. Don't jump from <h1> to <h4> - that's like having chapters without sections!
Correct:
html
<h1>Book Title</h1>
<h2>Chapter 1</h2>
<h3>Section 1.1</h3>
<h3>Section 1.2</h3>
<h2>Chapter 2</h2>
Incorrect:
html
<h1>Book Title</h1>
<h4>Random Section</h4> <!-- Skipped h2 and h3! -->
<h2>Chapter 1</h2>
Accessibility Note: Screen readers use headings to help visually impaired users navigate. Proper structure = better for everyone!

LEVEL 9: CONNECTING THE WEB WITH LINKS (Lecture - 3 Pages)
Page 1/3: Introducing the Anchor Tag
Wiza: "Welcome to Module 3! Today, we make your pages CONNECT! 🔗
The magic of the web is hyperlinks - clickable text that takes you somewhere else. In HTML, we create links with the anchor tag: <a>
Basic Link Structure:
html
<a href="https://www.webibo.com">Visit Webibo</a>
Breaking it down:
            * <a> = Anchor tag (creates the link)
            * href = Hypertext Reference (the destination URL)
            * Text between tags = The clickable link text
            * </a> = Closes the link
Try clicking: <a href="https://www.google.com">Search something</a>"
Page 2/3: Link Attributes and Types
Wiza: "Links can go to different places:
1. External Websites (Full URL):
html
<a href="https://www.wikipedia.org">Learn on Wikipedia</a>
2. Internal Pages (Relative Path):
html
<a href="about.html">About Us</a>
3. Same Page Sections (Anchor Links):
html
<a href="#contact">Jump to Contact</a>
<!-- Later in page: -->
<h2 id="contact">Contact Us</h2>
4. Email Links:
html
<a href="mailto:hello@webibo.com">Email us!</a>
5. Telephone Links:
html
<a href="tel:+1234567890">Call us</a>
Important Attribute: target="_blank"
Opens link in a new tab:
html
<a href="https://example.com" target="_blank">Open in New Tab</a>
```"


**Page 3/3: Best Practices for Links**
**Wiza:** "**Good Link Text:**
❌ DON'T: `<a href="...">Click here</a>`
✅ DO: `<a href="...">Download the guide</a>`


**Why?** Screen reader users often navigate by links. 'Click here' doesn't tell them where they're going!


**Accessibility Tip:** Add descriptive text:
```html
<a href="menu.pdf" aria-label="Download restaurant menu (PDF)">
  Download Menu
</a>
Remember: Links should:
            1. Clearly describe their destination
            2. Work when clicked
            3. Be visually distinguishable (usually blue and underlined)
            4. Change appearance when hovered
Example Page with Links:
html
<h1>My Favorite Resources</h1>
<p>Learn more at these sites:</p>
<ul>
  <li><a href="https://developer.mozilla.org">MDN Web Docs</a></li>
  <li><a href="tutorials.html">Our Tutorials</a></li>
  <li><a href="#resources" target="_blank">External Resources</a></li>
</ul>
Ready to connect your pages to the world wide web? 🌐"
