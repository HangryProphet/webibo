The HTML Document Structure

Wiza: "Every HTML document follows a specific structure. Here's the basic blueprint:"

Basic HTML Structure

<!DOCTYPE html>
<html>
  <head>
    <!-- Behind-the-scenes info -->
  </head>
  <body>
    <!-- Visible content -->
  </body>
</html>

Let's break this down:

1. <!DOCTYPE html> - This tells the browser, 'Hey, I'm using modern HTML!'

2. <html> - The root element that wraps EVERYTHING else

3. <head> - Contains invisible information (metadata, title, links)

4. <body> - Contains ALL visible content

Think of it like a house:

  • <!DOCTYPE html> = Building permit
  • <html> = The entire property
  • <head> = Blueprints (invisible to visitors)
  • <body> = The actual house (what people see)
Page 3/4

The Head vs Body Sections

Wiza: "Let's explore the difference between <head> and <body> with an example:"

Head vs Body Example

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
    <!-- This text WON'T appear on the page! -->
  </head>
  <body>
    <p>Welcome to my website!</p>
    <!-- This text WILL appear on the page! -->
  </body>
</html>

Key Difference:

<head> content: Never visible on the page itself

  • Page title (shown in browser tab)
  • Character encoding
  • Links to CSS files
  • Meta descriptions

<body> content: ALWAYS visible to visitors

  • Text paragraphs
  • Images
  • Buttons
  • Videos
  • Headings
Pro Tip: Right-click any webpage and select 'View Page Source' to see real HTML in action!
