🌅 The Image Tag

Wiza: "Welcome to the visual side of web development! 🌅 Today, we learn to add images with the <img> tag."

Important: The <img> tag is self-closing - it doesn't have a separate closing tag!

Basic Syntax:

<img src="puppy.jpg" alt="A cute golden retriever puppy">

The Two Required Attributes:

  1. src (source) - Path to the image file
  2. alt (alternative text) - Description for accessibility

Image Path Types:

  • Same folder: src="logo.png"
  • Subfolder: src="images/photo.jpg"
  • External URL: src="https://website.com/image.jpg"

🎨 Image Attributes and Best Practices

Wiza: "Essential Image Attributes:" 
<img 
  src="landscape.jpg"
  alt="Mountain landscape at sunset"
  width="800"
  height="600"
  title="Click to enlarge"
>

Why alt text matters:

  1. Screen readers read it to visually impaired users
  2. Displayed if image fails to load
  3. SEO - Search engines use it to understand images

Good vs Bad alt text:

❌ <img src="chart.jpg" alt="chart">

✅ <img src="chart.jpg" alt="2024 revenue growth chart showing 15% increase">

Image Formats:

  • .jpg - Photos (supports millions of colors)
  • .png - Graphics with transparency
  • .gif - Simple animations
  • .svg - Scalable vector graphics

📱 Responsive Images and Accessibility

Wiza: "Responsive Images: For images that scale with screen size:" 
<img 
  src="hero-large.jpg"
  srcset="hero-small.jpg 400w, hero-medium.jpg 800w, hero-large.jpg 1200w"
  sizes="(max-width: 600px) 400px, (max-width: 900px) 800px, 1200px"
  alt="Responsive hero image"
>

Accessibility Tips:

  1. Always include meaningful alt text
  2. Decorative images (purely visual): alt=""
  3. Complex images (charts, diagrams): Provide longer descriptions
