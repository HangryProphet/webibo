📋 Introduction to Lists

Wiza: "Welcome to Module 5! Today, we organize content with lists. 📋"

HTML offers three types of lists:

1. Unordered Lists (Bulleted) - <ul>

<ul>
  <li>Milk</li>
  <li>Eggs</li>
  <li>Bread</li>
</ul>
  • Shows bullets (default)
  • For items without specific order

2. Ordered Lists (Numbered) - <ol>

<ol>
  <li>Preheat oven</li>
  <li>Mix ingredients</li>
  <li>Bake for 30 minutes</li>
</ol>
  1. Shows numbers (1, 2, 3...)
  2. For steps, rankings, sequences

3. Description Lists - <dl> (less common)

<dl>
  <dt>HTML</dt>
  <dd>Structures web content</dd>
  <dt>CSS</dt>
  <dd>Styles web content</dd>
</dl>

🔗 Nesting and Styling Lists

Wiza: "Nested Lists (Lists inside lists):" 
<ul>
  <li>Fruits
    <ul>
      <li>Apples</li>
      <li>Bananas</li>
    </ul>
  </li>
  <li>Vegetables
    <ul>
      <li>Carrots</li>
      <li>Broccoli</li>
    </ul>
  </li>
</ul>

List Styling Attributes (Deprecated but good to know):

<!-- Type of bullet -->
<ul type="square">  <!-- circle, square, disc -->
  
<!-- Start numbering from -->
<ol start="5">  <!-- Starts at 5 -->
  
<!-- Numbering type -->
<ol type="A">  <!-- A, a, I, i, 1 -->

Modern Approach: Use CSS for styling instead of these attributes!

💡 Practical List Examples

Wiza: "Real-World List Examples:"

Recipe Page:

<h1>Chocolate Chip Cookies</h1>
<h2>Ingredients</h2>
<ul>
  <li>2 cups flour</li>
  <li>1 cup sugar</li>
  <li>Chocolate chips</li>
</ul>

<h2>Instructions</h2>
<ol>
  <li>Preheat oven to 350°F</li>
  <li>Mix dry ingredients</li>
  <li>Add wet ingredients
    <ol type="a">
      <li>Eggs first</li>
      <li>Vanilla second</li>
    </ol>
  </li>
  <li>Bake for 10-12 minutes</li>
</ol>

Navigation Menu (common use):

<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
    <li><a href="/contact">Contact</a></li>
  </ul>
</nav>

Pro Tips:

  1. Always use <li> inside <ul> or <ol>
  2. Nest properly with indentation
  3. Use semantic meaning: steps = ordered, features = unordered
  4. Lists improve SEO and accessibility

Lists help users scan content quickly - perfect for recipes, instructions, features, and navigation! 🗒️
