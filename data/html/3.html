HTML Basics

HTML (HyperText Markup Language) is the standard language for creating web pages. It describes the structure of a web page using a series of elements represented by tags.

Common HTML Elements

  • <h1>...</h1> headings for page titles and section labels.
  • <p>...</p> paragraphs for text.
  • <a href="">...</a> links to other pages or sections.
  • <img src="" alt=""> images with alternate text for accessibility.
  • <div> and <span> for grouping and styling content.

Basic Page Structure

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, Web!</h1>
    <p>This is my first HTML page.</p>
  </body>
</html>
💡 Pro Tip: Remember: keep your structure clear, use semantic tags when possible, and always include alt text for images. When you're ready, click Finish to continue.

The HTML Document Structure

Wiza: "Every HTML document follows a specific structure. Here's the basic blueprint:"

Basic HTML Structure

<!DOCTYPE html>
<html>
  <head>
    <!-- Behind-the-scenes info -->
  </head>
  <body>
    <!-- Visible content -->
  </body>
</html>

Let's break this down:

1. <!DOCTYPE html> - This tells the browser, 'Hey, I'm using modern HTML!'

2. <html> - The root element that wraps EVERYTHING else

3. <head> - Contains invisible information (metadata, title, links)

4. <body> - Contains ALL visible content

Think of it like a house:

  • <!DOCTYPE html> = Building permit
  • <html> = The entire property
  • <head> = Blueprints (invisible to visitors)
  • <body> = The actual house (what people see)

The Head vs Body Sections

Wiza: "Let's explore the difference between <head> and <body> with an example:"

Head vs Body Example

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
    <!-- This text WON'T appear on the page! -->
  </head>
  <body>
    <p>Welcome to my website!</p>
    <!-- This text WILL appear on the page! -->
  </body>
</html>

Key Difference:

<head> content: Never visible on the page itself

  • Page title (shown in browser tab)
  • Character encoding
  • Links to CSS files
  • Meta descriptions

<body> content: ALWAYS visible to visitors

  • Text paragraphs
  • Images
  • Buttons
  • Videos
  • Headings
