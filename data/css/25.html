CSS Colors and Text

Why Colors Matter

Colors are more than just decoration—they:

  • Guide users' attention to important content
  • Create mood and emotion on your website
  • Make text easier to read
  • Help with branding and identity
Quick Fact: The human eye can distinguish about 10 million different colors! But most websites use a carefully chosen palette of just 3-5 main colors.

Color Properties

CSS has two main color properties:

  • color - Changes the text color
  • background-color - Changes the background color
p {
  color: blue;
  background-color: lightgray;
}

Ways to Specify Colors

CSS gives you several ways to define colors:

1. Color Names

CSS recognizes 140 color names like red, blue, green, etc.

h1 {
  color: crimson;
  background-color: lightyellow;
}

2. Hex Colors

Hex codes start with # and use 6 characters (0-9, A-F):

p {
  color: #FF5733;        /* Orange-red */
  background-color: #F0F0F0;  /* Light gray */
}

3. RGB Colors

RGB uses red, green, and blue values (0-255):

.highlight {
  color: rgb(255, 87, 51);
  background-color: rgb(240, 240, 240);
}
Pro Tip: Hex codes are most common in web design. You can use online color pickers to find the perfect hex code for your design!

Text Styling Properties

Beyond colors, CSS offers many ways to style text:

Font Family

Changes the font (typeface):

body {
  font-family: Arial, sans-serif;
}

Font Size

Controls how big the text appears:

h1 {
  font-size: 32px;
}

p {
  font-size: 16px;
}

Font Weight

Makes text bold or light:

.important {
  font-weight: bold;  /* or use numbers: 700 */
}

.light {
  font-weight: 300;
}

Text Alignment

Controls horizontal positioning:

h1 {
  text-align: center;
}

p {
  text-align: left;   /* default */
}

.footer {
  text-align: right;
}
Best Practice: Always ensure good contrast between text and background colors. Dark text on light backgrounds (or vice versa) is easiest to read!
