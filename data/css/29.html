The CSS Box Model

What is the Box Model?

Every HTML element is actually a rectangular box! The CSS Box Model defines how these boxes are structured and spaced.

Each box consists of four layers (from inside to outside):

  1. Content - The actual text or images
  2. Padding - Space between content and border
  3. Border - A line around the padding
  4. Margin - Space outside the border (between elements)
Think of it like a picture frame:
  • Content = The photo
  • Padding = The mat board around the photo
  • Border = The frame itself
  • Margin = The space between frames on the wall

Padding - Internal Spacing

Padding creates space inside the element, between content and border:

/* All sides same */
.box {
  padding: 20px;
}

/* Individual sides */
.box {
  padding-top: 10px;
  padding-right: 15px;
  padding-bottom: 10px;
  padding-left: 15px;
}

/* Shorthand: top right bottom left (clockwise) */
.box {
  padding: 10px 15px 10px 15px;
}

Border - The Frame

Borders surround the padding and content:

/* Complete border */
.box {
  border: 2px solid black;
}

/* Individual properties */
.box {
  border-width: 2px;
  border-style: solid;  /* solid, dashed, dotted */
  border-color: black;
}

/* Rounded corners */
.box {
  border-radius: 10px;
}
Border Styles: solid, dashed, dotted, double, groove, ridge, inset, outset, none, hidden

Margin - External Spacing

Margin creates space outside the element, separating it from other elements:

/* All sides same */
.box {
  margin: 20px;
}

/* Individual sides */
.box {
  margin-top: 10px;
  margin-right: 15px;
  margin-bottom: 10px;
  margin-left: 15px;
}

/* Center an element horizontally */
.box {
  margin: 0 auto;  /* 0 top/bottom, auto left/right */
}

Width and Height

Control the size of the content area:

.box {
  width: 300px;
  height: 200px;
}

/* Or use percentages for responsive design */
.box {
  width: 50%;   /* 50% of parent element */
  height: 100%; /* 100% of parent element */
}

Putting It All Together

.card {
  width: 300px;
  padding: 20px;
  border: 1px solid #ccc;
  border-radius: 8px;
  margin: 20px auto;
  background-color: white;
}

This creates a nice card with:

  • 300px width
  • 20px internal spacing (padding)
  • 1px gray border with rounded corners
  • 20px space above/below, centered horizontally (margin)
  • White background
Pro Tip: In browser DevTools (F12), you can inspect any element and see its box model visualized with colors!
