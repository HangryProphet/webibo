Wiza: "Welcome to the colorful world of CSS! 🎨 I'm Wiza, and I'm so excited to show you how to make your websites beautiful!"

CSS stands for Cascading Style Sheets. If HTML is the skeleton of a webpage, CSS is the skin, clothes, and makeup! It controls how everything looks.

Quick Facts:

  • CSS is NOT a programming language
  • It's a styling language that works with HTML
  • Every browser understands CSS
  • You can change colors, sizes, layouts, and more!

Ready to add some style to your web pages? Let's begin!

⚙️ How CSS Works

Wiza: "CSS works by selecting HTML elements and applying styles to them. Here's the basic structure:" 
selector {
  property: value;
  property: value;
}

Example:

h1 {
  color: blue;
  font-size: 32px;
}

This means: "Make ALL <h1> elements blue and 32 pixels large."

Three Ways to Add CSS:

1. Inline CSS (directly on an element)

<p style="color: red;">This is red text</p>

2. Internal CSS (in the <head> section)

<head>
  <style>
    p { color: blue; }
  </style>
</head>

3. External CSS (separate file - best practice!)

<head>
  <link rel="stylesheet" href="styles.css">
</head>

🎯 CSS Selectors Basics

Wiza: "Selectors tell CSS which elements to style. Here are the most common:"

1. Element Selector (tags)

p { color: black; } /* All paragraphs */
h2 { color: green; } /* All h2 headings */

2. Class Selector (starts with .)

.special { color: purple; }

HTML:

<p class="special">This is purple!</p>

3. ID Selector (starts with #)

#main-title { font-size: 48px; }

HTML:

<h1 id="main-title">Big Title</h1>

Remember:

  • Classes can be used on MANY elements
  • IDs should be used only ONCE per page
  • External CSS is the cleanest way to style!
