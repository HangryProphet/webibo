Working with HTML Elements

What is the DOM?

The DOM (Document Object Model) is JavaScript's interface to HTML. It represents the page as objects that JavaScript can manipulate.

Selecting Elements:

// Select by ID
let header = document.getElementById("main-header");

// Select by class (returns array-like object)
let items = document.getElementsByClassName("item");

// Select by tag name
let paragraphs = document.getElementsByTagName("p");

// Modern method (CSS selector)
let element = document.querySelector(".special"); // First match
let allElements = document.querySelectorAll("div"); // All matches

Example HTML:

<h1 id="title">Hello World</h1>
<p class="info">Welcome to my site</p>
<div class="container">
  <button>Click me</button>
</div>
Pro Tip: querySelector() and querySelectorAll() are the most flexible methods because they accept any CSS selector!

Changing Content and Styles

Now let's change what users see on the page!

Changing Content:

let title = document.getElementById("title");
title.textContent = "New Title"; // Change text
title.innerHTML = "<em>Emphasized</em> Text"; // Change HTML

let button = document.querySelector("button");
button.innerHTML = "Click Here!";

Changing Styles:

let box = document.querySelector(".box");
box.style.color = "blue"; // Text color
box.style.backgroundColor = "yellow"; // Background
box.style.fontSize = "20px"; // Font size
box.style.display = "none"; // Hide element
box.style.display = "block"; // Show element

Adding/Removing Classes:

let element = document.querySelector(".my-element");
element.classList.add("active"); // Add class
element.classList.remove("old-class"); // Remove class
element.classList.toggle("hidden"); // Toggle class
Important: Use textContent for plain text and innerHTML for HTML content. CSS properties in JavaScript use camelCase (backgroundColor, not background-color).

Responding to Events

Let's make pages respond to user actions!

Event Listeners:

let button = document.querySelector("#myButton");

// Method 1: addEventListener (recommended)
button.addEventListener("click", function() {
  alert("Button clicked!");
});

// Method 2: onclick property
button.onclick = function() {
  console.log("Button was clicked");
};

// With arrow function
button.addEventListener("click", () => {
  button.style.backgroundColor = "green";
});

Common Events:

  • click - Mouse click
  • mouseover - Mouse enters element
  • mouseout - Mouse leaves element
  • keydown - Key is pressed
  • load - Page finishes loading
  • change - Form input changes

Complete Example:

// When page loads
document.addEventListener("DOMContentLoaded", function() {
  let button = document.getElementById("colorButton");
  let text = document.getElementById("message");
  
  button.addEventListener("click", function() {
    text.textContent = "Button clicked!";
    text.style.color = "red";
  });
});

This is the power of DOM manipulation - you can change anything on the page in response to user actions!
