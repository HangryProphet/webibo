Operators and Functions

Arithmetic Operators

let sum = 5 + 3;      // Addition: 8
let difference = 10 - 4; // Subtraction: 6
let product = 6 * 7;   // Multiplication: 42
let quotient = 15 / 3; // Division: 5
let remainder = 10 % 3; // Modulus (remainder): 1
let power = 2 ** 3;    // Exponentiation: 8 (2³)

Assignment Operators

let x = 10;     // Assign 10 to x
x += 5;         // Add 5 to x (now 15)
x -= 3;         // Subtract 3 from x (now 12)
x *= 2;         // Multiply x by 2 (now 24)
x /= 4;         // Divide x by 4 (now 6)

Comparison Operators

let isEqual = 5 == "5";    // true (loose equality)
let isStrictEqual = 5 === "5"; // false (strict equality)
let isGreater = 10 > 5;    // true
let isLess = 3 < 2;        // false
let isNotEqual = 5 != 10;  // true
Pro Tip: Always use === (strict equality) instead of == (loose equality) to avoid unexpected type coercion bugs!

Introduction to Functions

Functions are reusable blocks of code that perform specific tasks.

Creating Functions:

// Function declaration
function sayHello() {
  console.log("Hello!");
}

// Function with parameters
function greet(name) {
  console.log("Hello " + name + "!");
}

// Function that returns a value
function add(a, b) {
  return a + b;
}

Using Functions:

sayHello(); // Calls the function
greet("Wiza"); // Passes "Wiza" as argument
let result = add(5, 3); // Stores returned value (8)
console.log(result);

Arrow Functions (Modern Syntax):

const multiply = (a, b) => {
  return a * b;
};

// Shorter version (single expression)
const square = x => x * x;
Why Functions? Functions help you organize code, avoid repetition, and make programs easier to understand and maintain.

Practical Examples

Calculator Functions:

function calculate(operation, a, b) {
  if (operation === "add") {
    return a + b;
  } else if (operation === "subtract") {
    return a - b;
  } else if (operation === "multiply") {
    return a * b;
  } else if (operation === "divide") {
    return a / b;
  } else {
    return "Invalid operation";
  }
}

console.log(calculate("add", 10, 5)); // 15
console.log(calculate("multiply", 4, 6)); // 24

Temperature Converter:

function celsiusToFahrenheit(celsius) {
  return (celsius * 9/5) + 32;
}

console.log("20°C is " + celsiusToFahrenheit(20) + "°F");

Remember:

  • Functions make code reusable and organized
  • Parameters are inputs, return values are outputs
  • Always test your functions with different inputs!
