Getting Started with JavaScript

Quick Facts About JavaScript:

  • JavaScript IS a programming language
  • It runs in your web browser
  • It can change HTML and CSS dynamically
  • It responds to user actions (clicks, typing, etc.)
  • It's NOT the same as Java!
Fun Fact: JavaScript was created in just 10 days in 1995 by Brendan Eich at Netscape. Today, it's one of the most popular programming languages in the world!

How JavaScript Works

JavaScript works by manipulating HTML elements and responding to events. Here's how to add it to your page:

Three Ways to Add JavaScript:

1. Inline JavaScript (directly in HTML - not recommended)

<button onclick="alert('Hello!')">Click me</button>

2. Internal JavaScript (in <script> tags)

<script>
  alert('Welcome to my page!');
</script>

3. External JavaScript (separate file - best practice!)

<script src="script.js"></script>

Basic JavaScript Syntax:

// This is a single-line comment
console.log('Hello World!'); // Shows in browser console
The Console: Press F12 in your browser to open Developer Tools, then click "Console" to see JavaScript output and errors. This is your debugging best friend!

Variables and Data Types

Variables store data so we can use it later in our code.

Declaring Variables:

let message = "Hello"; // Can be changed later
const pi = 3.14; // Cannot be changed
var oldWay = "Not recommended"; // Old method

Basic Data Types:

let text = "Hello"; // String (text)
let number = 42; // Number
let isTrue = true; // Boolean (true/false)
let nothing = null; // Empty value
let notDefined; // undefined

Using Variables:

let name = "Wiza";
let age = 25;
console.log("My name is " + name); // String concatenation
console.log("I am " + age + " years old");

Remember:

  • Use let for variables that change
  • Use const for constants that don't change
  • Strings use quotes (single or double)
  • JavaScript is case-sensitive!
